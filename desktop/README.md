# Replay Live Helper

다운로드한 ZIP을 풀고 **Replay Live Helper**를 실행합니다. 설치 확인과 PC 로그인 시 자동 실행 여부를 각각 선택합니다. 웹으로 돌아오면 도우미가 연결됩니다. 설치에는 관리자 권한이나 Python·FFmpeg의 별도 설치가 필요하지 않습니다.

macOS는 `~/Applications/Replay Live Helper.app`, Windows는 `%LOCALAPPDATA%\ReplayLiveHelper`에 설치됩니다. 이 PC의 네트워크·임시 저장 공간을 사용하며 원본 플랫폼의 로그인·봇 확인을 우회하지 않습니다. 다운로드된 영상은 클라우드 업로드 후 임시 폴더에서 삭제합니다.

macOS에서 앱을 다시 열면 자동 시작 설정과 제거 메뉴가 나옵니다. Windows에서 앱을 다시 열어 자동 시작 여부를 변경할 수 있고 설정 → 앱 → 설치된 앱에서 제거할 수 있습니다. Windows에서는 실행 파일이 종료된 뒤 안내된 설치 폴더를 삭제해야 합니다.

최초 버전은 개발 검증 패키지입니다. 일반 배포 전에 macOS Developer ID 서명·공증 및 Windows 코드 서명이 필요합니다. OS의 보안 경고를 끄거나 우회하지 마세요. 앱 실행이 차단되면 정식 서명된 배포본을 기다리세요.

FFmpeg는 빌드 환경의 배포본을 함께 포함합니다. 릴리스 담당자는 해당 배포본의 GPL/LGPL 조건, 소스 제공 및 저작권 고지를 검토·동봉해야 합니다. 앱에는 서비스 비밀키·클라우드 로그인 토큰·브라우저 쿠키가 포함되지 않습니다.
