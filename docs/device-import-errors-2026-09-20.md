# PC 영상 가져오기 오류 표시 검증 — 2026-09-20

## 변경

- 도우미 연결 및 가져오기 실패를 가져오기 버튼 바로 아래에 지속적으로 표시한다. 오류 카드로 초점과 스크롤을 이동하고 재시도·MP4 업로드 전환을 제공한다.
- 서버 작업 요청, PC 다운로드, 클라우드 업로드, 완료 확인 단계를 구분한다. 최종 실패 응답만 수신해도 해당 단계를 유지한다.
- `SourceImportError`가 `DEVICE_IMPORT_*` 코드를 `SOURCE_UNAVAILABLE`로 바꾸던 문제를 고정 코드만 허용하는 하위 예외로 수정했다. 원격 응답 본문·토큰·서명 URL은 오류 메시지로 전달하지 않는다.
- 업로드 대상에 공식 Vercel PUT 주소 `https://vercel.com/api/blob/`를 정확히 허용한다. 다른 Vercel 경로와 유사 도메인은 거부하며 저장소에 작업 인증 토큰을 전달하지 않는다.

## 검증

- Python 도우미·작업 API 테스트 36개 통과: 단계별 실패, 권한 취소, 업로드 대상 검증, 파일 정리 및 완료 요청 재시도 포함.
- 프런트엔드 테스트 191개 통과. TypeScript 검사, lint, Vercel 빌드 통과.
- 실제 Chrome을 CUA로 조작해 실제 `LocalImportFailure` 컴포넌트를 사용하는 로컬 합성 실패 화면을 확인했다. 오류 메시지 노출, 오류 카드 초점, 재시도 콜백 1회 실행, MP4 선택 화면 전환을 확인했다. 임시 검증 페이지는 제거했다.
- 이 로컬 UI 시험은 운영 영상 가져오기 성공 증거가 아니다.

## 운영에서 확인된 미해결 항목

운영 main `5918f47`에서 사용자 계정 로그인과 PC 도우미 연결 후 제공된 YouTube 링크로 실제 가져오기를 실행했다. 작업 생성 201 및 도우미의 작업 조회 200 이후 업로드 준비 API가 400을 반환했고, 대응하는 웹 저장소 제어 요청에서 502가 발생했다. 실패 보고와 작업 정리 요청은 성공했다.

같은 다운로드 경로로 원본 영상을 PC에 내려받는 것은 성공했다(1,194,527바이트). 운영 실패를 YouTube 봇 차단이나 다운로드 실패로 단정할 수 없다. 저장소 제어 경로의 502 원인은 현재 확인되지 않았다. 이번 변경은 실패 단계를 보존하고 화면에 표시하며, 서명 발급 이후의 Vercel 업로드 대상 거부 문제도 수정한다. 저장소 제어 502가 해결되었다고 주장하지 않는다.

이번 변경은 작업 브랜치 검증 상태다. PR 승인·develop/main 반영·운영 배포 후 같은 링크로 업로드와 보관함 준비 완료까지 재검증해야 한다.
